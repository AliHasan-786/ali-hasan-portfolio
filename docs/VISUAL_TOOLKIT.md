## First Applied Figure

The opening context sorter is a custom, light-theme SVG cabinet. Its three
drawers represent protected context, review and a public-label candidate.
Selecting an existing authored policy example opens its drawer and updates the
excerpt and explanation from the same state. No classifier runs and no score
is invented. The illustrated hardware is a metaphor, not a physical simulator.

Anatomy's geometry core is vendored unchanged with its full MIT notice. The
React drawing, cabinet and policy mapping are custom. UI/UX search informed
native pressed buttons, visible focus and non-hover operation. The 3Dviz
kinematics guidance informed the explicit authored-state boundary. Animation
guidance was read; no Animation Skills video renderer was run or shipped.

## Project Direction

- Drift: use depth only if actual representation coordinates support it. Do not
  invent embedding points or suggest that a projection preserves all distances.
- Watermarking: use a signal instrument over the preserved score arrays. Separate
  word-level mechanics from detector evidence and missing rewritten text.
- DeepShield: prioritize synchronized original/protected/edited comparisons and
  visible quality cost. No synthetic image should stand in for an unrun defense.
- Housing: use the actual event-day ledger for queue motion. Never infer an
  intra-day sequence from daily aggregates.
- Brunch Index: preserve the cartographic essay. Decorative 3D adds no evidence
  to metro/year comparisons.
- Fairness and StanceBench: show paired language and routing decisions clearly.
  The same interface must retain adverse, missing and incompatible cells.

## Acceptance

Test keyboard and touch controls, 320px reflow, tablet layouts, reduced motion,
source links and missing-data states. Keep text readable while geometry moves.
Pause continuous rendering offscreen if a later figure needs it. No WebGL is
required for the context sorter. Compare the real browser output with the
intended behavior; a build or geometry test is not visual approval.
