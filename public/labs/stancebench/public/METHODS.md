# StanceBench Methods

Use this page to compare six ways of talking about the same scam claim. Pick a
topic and speech type, then inspect the saved decision, study expectation, and
source hashes for that record.

The public page replays 60 approved synthetic examples from one cached local
TF-IDF baseline: 48 matched scam records and 12 unrelated controls. Hosted
comparisons have not run, so this page does not rank hosted models or report a
completed study.

The package is built only after the repository checks the frozen input list,
action mapping, and SHA-256 manifest. `provenance.json` records the public-safe
hashes and baseline identity behind this page. Opening the page does not call a
provider.

The displayed records are approved, synthetic, low severity, and CC BY 4.0.
This public page does not change the frozen artifact's local release candidate
status or authorize provider access, new data, or a new study run.
