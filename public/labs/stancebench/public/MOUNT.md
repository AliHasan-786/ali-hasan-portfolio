# StanceBench Mount

The portfolio coordinator mounts this reviewed static package at
`/labs/stancebench/`.

The package uses relative asset links, so its scripts, styles, derivative,
methods, provenance, metadata, and thumbnail load from that path. The return
link points to `/`, the portfolio hub.

The page is a public partial-baseline view. It replays 60 approved synthetic
examples from one cached local TF-IDF baseline. Hosted comparisons have not
run. Publishing this page does not change the frozen artifact's local release
candidate status or authorize provider access, new data, or a new study run.
